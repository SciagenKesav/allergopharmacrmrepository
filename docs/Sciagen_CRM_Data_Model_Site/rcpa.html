Sciagen CRM / RCPA Audits

RCPA Audits Data Model

Entities and relationships for retail chemist prescription audits, competitor brands, personal order booking and audit targets.

Scroll or zoom the diagram. In the PDF it is scaled to the page.

Entities/Objects Included

Personal Order Booking Line, Product, RCPA Audit, RCPA Competitor Brand, RCPA Molecule Line, RCPA Target, Sciagen Account, Territory

How it works in our org

  • An RCPA Audit is done at a chemist (an account) in a territory.
  • Each audit has one Line per molecule and prescriber; each line lists Competitor brands with their quantities.
  • POB Lines record the personal order booking taken during the audit. RCPA Target sets the HCPs to be audited.
