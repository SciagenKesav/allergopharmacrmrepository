Data Change Requests Data Model

Entities and relationships for requests to change account data, with approval comments.

Scroll or zoom the diagram. In the PDF it is scaled to the page.

Entities/Objects Included

Data Change Request, Sciagen Account

How it works in our org

  • A rep raises a DCR of type New HCP, New HCO, Edit HCP, Edit HCO or Territory Unassign. Key Account Manager edits to accounts also arrive as DCRs rather than saving directly.
  • The requested values travel as a payload and a summary. An administrator reviews it and approves or rejects it with a reason; approval applies the change to the account.
