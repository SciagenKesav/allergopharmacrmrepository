Sciagen CRM / Support Center

Support Center Data Model

Entities and relationships for in-app support requests, comments, support settings and device reset requests.

Scroll or zoom the diagram. In the PDF it is scaled to the page.

Entities/Objects Included

Call Visit Report, Device Reset Request, Support Comment, Support Request, Support Setting

How it works in our org

  • A rep raises a Support Request from the app in a category such as Unlock Submitted Call, Unlock Monthly Plan, Data Correction, Sync Problem, App Issue or Access or Login. It has a priority, an SLA due time and an awaiting-whom marker.
  • A request can point at a call report or a monthly plan; an unlock request that is resolved as Unlocked reopens that record.
  • Comments form the thread. Support Settings hold SLA hours, auto-close days, daily limits and notification switches.
  • Device Reset Request lets a rep ask to wipe local app data; the manager approves it and a one-time code is issued.

Device Reset Request Device_Reset_Request__c 7 fields

A rep's request to wipe local app data on their iPad (Profile > Reset Local Data). Requires the rep's manager to approve via Salesforce's own Approval Process before a one-time code is generated and handed to the rep (by phone or email) -- the app only proceeds with the wipe once that code is entered correctly. Private sharing: a rep can only see their own requests; the approver sees it via the approval process's temporary access grant.
