Sciagen CRM / Call Planning Controls

Call Planning Controls Data Model

Entities and relationships for monthly call plans, plan freezing and deviation, geofence rules, and the settings that restrict when calls can be created or submitted.

Scroll or zoom the diagram. In the PDF it is scaled to the page.

Entities/Objects Included

Call Backdate Limit, Call Submission Restriction, Geofence Rule, Geofence Setting, Holiday, Monthly Call Plan, Planned Call / Event, Territory

How it works in our org

  • Each rep has one Monthly Call Plan per month. Freezing it records the number of calls and HCPs; planned calls inside a frozen plan keep their original date and type so deviation can be measured.
  • Unlocking a frozen plan is logged with who, when and why, and counted.
  • Geofence Rule and Geofence Setting control whether a check-in must be within a radius of the HCO, per user or per territory.
  • Call Backdate Limit and Call Submission Restriction cap how far back a call can be entered and when a report may be submitted. Holidays come from custom metadata.

Geofence Setting Geofence_Setting__c 3 fields

Geofence rules for rep check-in — the default radius around an HCO and whether a check-in outside it is blocked. A Hierarchy Custom Setting so an admin sets one org-wide default and can override it per-Profile or per-User from Setup with no app deploy. The iPad caches the resolved values so the rule is enforced offline.

Call Submission Restriction Call_Submission_Restriction__c 12 fields

Per-calendar-month deadline for submitting a Call Visit Report dated in a prior month — e.g. December's field set to 10 means a call dated in December can no longer be Submitted once it's past January 10th. Each month is configured independently so, for example, a fiscal year-end month can have a tighter deadline than the rest. A blank field means that month has no submission deadline. A Hierarchy Custom Setting, same as Call_Backdate_Limit__c, so an admin can set one org-wide default and override it per-Profile or per-User from Setup with no app deploy needed.
